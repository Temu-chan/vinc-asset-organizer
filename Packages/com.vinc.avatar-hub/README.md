# V.inc Avatar Hub

VRChat ギミック制作向けの Unity エディター拡張です。
**案件フォルダーの自動作成 → 「何を含めるか」のプロファイル登録 → UnityPackage の書き出し（単発・シーケンス）** を 1 つのウィンドウで行います。
複数の unitypackage を順番にまとめて入れる **シーケンスインポート** と、手で作った unitypackage からプロファイルを作る機能もあります。

- メニュー：`V.inc / Avatar Hub`
- ウィンドウ：既定は独立したウィンドウ。前回閉じたときの位置と大きさで開きます（はじめては Unity 本体の中央）。最小サイズは 640×480（設定で Unity のタブとして開くようにもできます）
- 対応：Unity 2022.3（VRChat SDK / Modular Avatar 環境で動作確認）
- 依存パッケージなし（MA の参照もシリアライズ参照として追跡するため、MA の DLL を直接参照しません）

## 画面の流れ

| | 画面 | できること |
|---|---|---|
| ホーム | 何をしたいですか？ | やりたいことを選ぶと、注釈つきのスクリーンショットで手順を説明。「〜とは？」の解説、最近使ったもの |
| 設定 | 右上の「設定」 | テーマ（Unity のグレー・ダーク・ライト）、アクセントカラー、サイドバーに出すワークフロー、ウィンドウの開き方、保存場所 |
| ① | プロジェクト作成 | 名前を入れてチェックするだけでフォルダー一式を作成。作成場所（親フォルダー）の選択、タグ付け、あとからのフォルダー追加 |
| ② | プロファイル登録 | 自動登録（プレハブ/フォルダーをドロップ → 依存を自動チェック）、手動登録、UnityPackage から作る。名前・パッケージ名・タグ・書き出し先 |
| ③ | エクスポート | 単発：`名前 [種別] [Ver] [日付] [時刻]` をクリックで付け外し。シーケンス：複数をまとめて順番に書き出し |
| ④ | シーケンスインポート | 複数の unitypackage をキューに並べて、上から順番にインポート。行ごとにプロファイルも作れる |

上部の検索欄（Ctrl+F）で、プロジェクト・プロファイルを名前やタグから探せます。
ひらがな/カタカナ・全角/半角・大文字/小文字・`_` `-` の違いは無視します（例：「くじら」で「クジラ」タグがヒット）。

## 書き出し名のルール

```
productC                               … 何も付けない
productC_Ver0.0.1                      … バージョン
productC_Ver0.0.1-2026_10_25           … バージョン＋日付
productC_Ver0.0.1-2026_10_25-18_51     … バージョン＋日付＋時刻
productC_2026_10_25-18_51              … 日付＋時刻
productC_Debug_Ver0.0.1                … 種別（ラベルは設定で変更可）＋バージョン
```

- 名前の後ろは必ず `_`、バージョン・日付・時刻のあいだは `-`
- バージョンは 0.0.1〜9.9.9。上げると下の位は 0 に戻る（0.0.9 → 0.1.0、1.2.5 の真ん中 → 1.3.0）
- 初回は 1.0.0、2 回目以降は前回の番号が入り「前回のバージョンは〜でした」と表示
- シーケンスでは、日付・時刻は「エクスポート」を押した瞬間の値を全件に使う

## プロファイルの仕組み

- **フォルダーにチェック**＝中身ぜんぶ（**これから増えるファイルも**）。ファイル単位の除外もできる
- 「基準フォルダー」（プロジェクトのフォルダー）の**外**のファイルは「外部」扱いで、最初はチェックしない（アバター本体や他人の素材の混入防止）
- Packages 配下（VRCSDK・MA・lilToon など）は unitypackage に入れられないため対象外
- 書き出し時に起点プレハブの依存を再チェックし、**未登録の新しい依存**（入れ忘れ）や**見つからない登録**を警告
- 書き出すのは解決したファイルとその親フォルダーだけ（依存の自動追加はしない）

## UnityPackage から作る・シーケンスインポート

手で作っていた unitypackage を Avatar Hub に移すための機能です。

- unitypackage の中身（GUID と元のパス）を、インポートせずに読みます。アセット本体は読み込みません
- プロジェクトとは **GUID** で照らし合わせます。インポートしたあとに移動・名前変更したファイルも、いまの場所で登録します
- まだ入っていないファイルがあれば、自動でインポートしてからプロファイルを作ります
- 登録するのは **入っていたファイルだけ**（フォルダーごとにはしません）。ほかのプレハブから使われていないプレハブを起点にして、次からの入れ忘れチェックに使います
- 名前とバージョンはファイル名から読みます（例：`Ring_Ver1.0.2-2026_10_28` → 名前 `Ring`、次のエクスポートは 1.0.2 の続きから）
- `Packages/` など Assets の外のファイルは、unitypackage に入れられないので登録しません
- 作ったプロファイルはすぐに保存します（Ctrl+Z で取り消せます）。注意点（入れ忘れの可能性・見つからないファイル）は結果に表示します
- 同じ unitypackage からもう一度作ったとき：中身がまったく同じプロファイルがあれば「既にあります」と出して作りません。同じ名前で中身が違えば、何が変わるかを見せて「上書きする（名前・タグ・書き出し先はそのまま）／別名で作る／作らない」を選んでもらいます

**名前の重なり**：プロファイルは同じ名前で保存しません。重なるときは「名前 (2)」のように番号を付けます（JSON のファイル名と同じ）。unitypackage の名前は元のままなので、書き出すファイル名は変わりません。以前のバージョンで同じ名前のまま保存されたもの（ファイル名だけ「(2)」）は、開いたときに名前をファイル名に合わせます。

**黄色の「!」（衝突）**：Unity のインポート画面で黄色の「!」が付くファイル（同じパスに GUID の違う別のファイルがある）は、そのまま入れるとプロジェクトのファイルが上書きされます。

- UnityPackage から作る：衝突があるときだけ「Unity の画面で入れる（入れるファイルを選べる）／このまま入れる（上書き）／やめる」を選びます。無ければ確認なしで入れます
- シーケンスインポート：「止めて確認する（おすすめ）」か「無視して入れる」を選べます。止まった行では「Unity の画面で入れる／このまま入れる／飛ばす」を選ぶと続きを進めます

スクリプト入りのパッケージでは途中でコンパイル（ドメインリロード）が走りますが、キューは保存してあるので終わると続きから進みます。

## 保存場所（すべて JSON）

PC 全体で共通です（どの Unity プロジェクトを開いても同じ一覧が出ます）。

| データ | 場所 | 共有 |
|---|---|---|
| フォルダー構成プリセット | `ドキュメント/V.inc/Avatar Hub/Presets/*.preset.json` | 書き出し / 読み込み |
| プロジェクト記録 | `ドキュメント/V.inc/Avatar Hub/Projects/*.project.json` | 書き出し / 読み込み |
| プロファイル | `ドキュメント/V.inc/Avatar Hub/Profiles/*.profile.json` | 書き出し / 読み込み |
| 設定 | `ドキュメント/V.inc/Avatar Hub/settings.json` | — |
| 書き出し履歴（前回のバージョン） | `ドキュメント/V.inc/Avatar Hub/history.json` | — |
| ウィンドウの位置と大きさ | `ドキュメント/V.inc/Avatar Hub/window.json` | — |
| シーケンスインポートのキュー | `<Unityプロジェクト>/Library/VIAH/import-*.json`（Unity プロジェクトごと） | — |
| unitypackage の既定の出力先 | `<Unityプロジェクト>/Exports/`（設定・プロファイルごとに変更可） | — |

旧バージョン（Asset Organizer）のデータ（`%AppData%/V.inc/AssetOrganizer` と `<Unityプロジェクト>/AssetOrganizer`）は、初回起動時に自動でコピーして引き継ぎます。

## 元に戻す（Undo）

Ctrl+Z / Ctrl+Y（Edit メニューにも「VIAH: 〜」として表示）。入力途中の内容、フォルダー構成の編集、プロファイルの選択、保存・削除・複製・読み込み、設定の変更、シーケンスインポートのキューの編集、フォルダーの作成（取り消すと空のフォルダーを削除）を戻せます。
unitypackage・JSON の書き出し、unitypackage のインポート（入ったファイルはそのまま。一緒に作ったプロファイルは戻せます）、画面の移動・検索は戻せません。画面を移ると、その画面の入力途中の Undo は消えます。

アセットは GUID とパスの両方で記録するため、フォルダーを移動・リネームしても追従します。
他の人のプロファイルを使うときは、同じアセット（同じ GUID）がプロジェクトに入っている必要があります。

## 開発用テスト

`Tests/Editor` の自己テスト・画面テスト・通しテストは、スクリプト定義シンボル `VINC_VIAH_DEV` を追加したときだけコンパイルされます
（Player Settings → Scripting Define Symbols）。有効にするとメニュー `V.inc / 開発` から実行できます。
テストは `Assets/VIAH_Sample` などのサンプルを作るので、確認後は削除してください。
