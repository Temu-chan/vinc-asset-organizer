V.inc Avatar Hub を VCC に追加

VRChat Creator Companion（VCC）を開いています…
ブラウザに「VRChat Creator Companion を開きますか？」と出たら 開く を押してください。 VCC の確認画面で I Understand, Add Repository を押すと追加されます。

VCC に追加する
うまく開かないとき（手動で追加）
  1. VCC を開き、Settings → Packages → Add Repository を押す
  2. 次の URL を貼り付けて Add を押す

追加後は、各プロジェクトの Manage Project から「V.inc Avatar Hub」を追加してください。

⚠ このツールは社内の許可された人のみ使用できます。このページの URL を社外に共有しないでください。
